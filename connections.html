🔗 Connect once — saved for good

Paste the Web app link of your Google Apps Script (it ends with /exec). After it connects, the app remembers it permanently, even after restarts.

How do I get the link?
  1. Create a Google Sheet → Extensions → Apps Script.
  2. Paste the file google-sheet-script.gs and Save.
  3. Deploy → New deployment → Web app (Execute as: Me, Access: Anyone).
  4. Copy the Web app URL (ends with /exec) and paste it above.
