2. Telegram bot delivery

AMBAR sends all order cards using BOT_TOKEN only. No Telegram Business connection, TG_API_ID, TG_API_HASH, or personal Telegram login is required. Order cards are delivered only to the main admin and submitting admin. Customers never receive order cards. Each admin must press Start in the AMBAR bot to receive a private copy. No personal-account connection is required.

5. Assign people who can USE the app

Each person opens the app from Telegram; if they are not assigned they see their Telegram ID to send you.
