2. Telegram bot connection

The main admin connects the shared AMBAR bot from Telegram Settings → Telegram Business → Chatbots, grants access to the chats and enables “Reply to messages”. First enable Business Mode for the bot in @BotFather. This shared bot connection does not require a personal Telegram login code. Only the main admin and Telegram IDs assigned below can access the AMBAR app. An assigned admin may optionally connect their own personal Telegram account from the app; Telegram delivers that login code through its own official login flow, never through the AMBAR bot. Personal-account login requires TG_API_ID and TG_API_HASH from my.telegram.org → API development tools.

5. Assign people who can USE the app

Only the main admin and Telegram IDs assigned here can use AMBAR. Everyone else is blocked. Each assigned person must open the Mini App from their own Telegram account.
